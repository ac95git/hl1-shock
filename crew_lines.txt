// crew_lines.txt -- what the Crew say (docs/ROADMAP.md, "The Crew").
//
// The repo copy is the source of truth.  Copy it to the mod directory by
// hand after every change, like records.txt.  It is read by the server
// on every map load, so a changed file shows on the next `map` or `restart`.
//
// FORMAT -- keyed blocks, line-based, as records.txt:
//
//   <string id>
//   {
//       kind  <miner | security | construction | technician>
//       pool  <use | hello | idle | stare>     (use when absent)
//       text  <one line of what prints; repeat for more lines>
//       wav   <path under sound/>              (optional)
//   }
//
// A use press prints a random line from the kind's `use` pool, and plays
// its wav if it has one.  A Crew member with `line` set in the map says
// that id and nothing else -- for the three who must say something exact.
//
// hello, idle and stare are UNPROMPTED and never print: a line there does
// nothing until it has a wav.  Until then that kind is silent unprompted.
// A wav named here but missing from sound/ is dropped with a console line,
// so writing the line before recording it is fine.
//
// Ids are not saved; rename freely, but a `line` in a map names one.
//
// Keep a line short: it is read in passing, over the player's shoulder.
// The text wraps at 60 characters on its own.
//
// Every line below is a FIRST DRAFT, written by the agent on 2026-09-24
// to make the slice testable.  Andrei's to rewrite.
