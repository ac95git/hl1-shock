// records.txt -- the mod's Records (docs/ROADMAP.md, "Pillar 1: Records").
//
// The repo copy is the source of truth.  Copy it to the mod directory by
// hand after every change, like sprites/hud.txt and the FGD.  It is read
// by the client alone; `records_reload` re-reads it without a map load.
//
// FORMAT -- keyed blocks, line-based, in the manner of titles.txt:
//
//   <string id>
//   {
//       id        <number, 1..511 -- this IS the saved bit>
//       category  <the tab groups by this; "Guidance" is pinned on top>
//       title     <what the tab and the reader's heading show>
//       source    <one line: where the document physically is>
//       revocable <0 or 1; Guidance only, and nothing reads it until slice 3>
//       body
//       ...every line until the closing brace, verbatim...
//   }
//
// A blank line inside a body is a paragraph break.  *Stars* mark the one
// emphasis, drawn in the suit's colour -- for codes, and for *[REDACTED]*.
// Keep an emphasised span off the end of a long line: the wrap does not
// know about it, and a span broken across two lines reads as two stars.
//
// THE ID IS SAVED.  Once a Record has been played, its id is stable
// forever and is never reused -- the Skill rule.  Ids run to 511.
//
// Records are SHORT.  They are read in real time in an unsafe world, so a
// long document is a series found apart, not one wall of text.

// ---------------------------------------------------------------------
// Guidance -- ordinary Records in a pinned category, handed over and
// taken back by record_grant (slice 3).  Written in the advisor's voice.
// ---------------------------------------------------------------------

	category  Notice

	body

	corridor are on the maintenance lock and will not answer a badge.

	Maintenance override for this corridor is *4471*. Do not write it down.
}

notice_pit_bottom_board
{
	id        9
	category  Notice
	title     Tag Board -- Pit Bottom
	source    Tag board, the onsetter's hut by the shaft
	body
	Every man takes his tag going down and hangs it back going up. The
	onsetter counts the hooks before the cage rides. Suits are worn past the
	drift door; kit is in the dry, first terrace, east side. Decontamination
	is on the door and runs on its own.

	One tag is still on its hook, three days old, with a strip of tape over
	the name.
}

notice_pump_room
{
	id        3
	category  Notice
	title     Pump Room -- Standing Order
	source    Laminated card, pump control
	body
	Do not start the pumps with the lower gallery occupied. The gallery
	floods to waist height in under a minute and the stair gate closes on
	the same interlock.

	If you cannot see the gallery, assume it is occupied.
}
